## Description

**Overview**
This image builds on top of its base image by adding an MPI library with GPU
support, based on an MPICH build. It also includes the AWS-OFI-NCCL plugin to
enable RCCL communication over the interconnect network using libfabric. The
rccl-tests and OSU micro-benchmarks suite are included for performance and
functionality validation.

**Details**
Base image: lumi-multitorch-libfabric-u24r72f21m50t211
MPI implementation: MPICH 5.0.1
Components:
  - MPICH 5.0.1 (from http://www.mpich.org/static/downloads release tgz for 5.0.1)
  - AWS-OFI-NCCL 1.21.1 (from https://github.com/aws/aws-ofi-nccl commit 2475c4c)
  - RCCL Tests (from https://github.com/ROCm/rocm-systems commit 485afdf)
  - OSU micro-benchmarks 7.5.2 (from https://mvapich.cse.ohio-state.edu/download/mvapich release tgz for 7.5.2)
